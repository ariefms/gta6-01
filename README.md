Solara Bay is an open-world crime game in the browser: drive a sun-soaked coastal city, steal cars, outrun the Bay Patrol's wanted system, and work a five-mission story with Dio Santana — from a first stolen car to the Big Score at Bay National.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080/ and press Enter. No build step, no network — the game is static files under `game/`, with three.js vendored locally.
